## 1. 產品概述

- **目的**：輸入每月收入，用百分比或固定金額把收入分配到各個支出／儲蓄項目，讓財務規劃變得輕鬆好玩。
- **平台**：手機優先（mobile-first）網頁，用手機瀏覽器開啟即可；桌機也能正常顯示。
- **使用方式**：單一頁面，不需註冊登入，資料只存在使用者自己的瀏覽器。

## 2. 頁面結構（由上到下）

1. 標題列（App 名稱、⋯ 選單）
2. 方案標籤列
3. 收入區塊
4. 支出區塊
5. 摘要列（固定在畫面底部，含吉祥物）

## 3. 方案（多組）

- 頁面上方是可左右滑動的**方案標籤列**，例如：`我的方案`｜`加薪後`｜`＋`
- 每個方案各自擁有一份收入和支出清單。

| 功能 | 說明 |
|---|---|
| 新增 | 點「＋」建立新方案，內容為第 8 節的預設範例 |
| 複製 | 複製目前方案，方便比較不同情境 |
| 重新命名 | 點目前方案標籤的 ⋯ 選單 |
| 刪除 | 需二次確認；至少保留一組方案（只剩一組時刪除按鈕停用） |
| 切換 | 點標籤即切換；記住上次開啟的方案 |

## 4. 收入區塊

| 欄位 | 類型 | 規則 |
|---|---|---|
| 項目名稱 | 文字 | 例如：薪水、股息、兼職 |
| 金額 | 數字 | ≥ 0，可有小數；空白視為 0。點擊開啟計算機輸入（見 5.5） |

- 「＋ 新增收入」：在清單最後新增一列空白項目。
- 每列有刪除按鈕。
- 每列左側有拖曳把手 ⠿，可拖曳調整順序（見 5.6）。
- **收入總計** = 所有金額加總，即時更新。

## 5. 支出區塊

### 5.1 欄位

| 欄位 | 類型 | 規則 |
|---|---|---|
| 圖示 | emoji | 點擊可從清單選擇（🍙 🏠 🐷 🎮 🚌 💊 📚 🎁 …），預設 💸 |
| 項目名稱 | 文字 | 例如：吃飯、房租、儲蓄 |
| 百分比 % | 數字，可編輯 | 0～100，可有小數 |
| 金額 | 數字，可編輯 | ≥ 0。點擊開啟計算機輸入（見 5.5） |

### 5.2 % ⇄ 金額 雙向計算

- 填 %：金額 = 收入總計 × %
- 填金額：% = 金額 ÷ 收入總計
- **最後編輯的欄位是該列的「主值」**，以實線框標示；另一欄是虛線框。

收入總計改變時：

| 該列主值 | 結果 | 例子 |
|---|---|---|
| % | % 不變，金額重算 | 吃飯 30% |
| 金額 | 金額不變，% 重算 | 房租固定 13,000 |

- 收入總計為 0 時，以金額為主值的列，其 % 顯示「—」（不顯示錯誤）。

### 5.3 區塊小計

- **已分配**：% 合計與金額合計
- **未分配**：100% − 已分配 %，以及對應金額

### 5.4 操作

- 「＋ 新增支出」、每列刪除按鈕。
- 每列左側有拖曳把手 ⠿，可拖曳調整順序（見 5.6）。

### 5.5 金額計算機

收入和支出的**金額欄位（NT$）**點下去時，不叫出手機鍵盤，而是從底部滑出簡易計算機，方便把好幾筆金額加總後再填入。

- 標題：「〔項目名稱〕的金額」，例如「薪水的金額」；還沒填名稱時顯示「收入金額」或「支出金額」。
- 顯示區：上方是算式（例如 `1,200 + 350 × 2`），下方大字是結果預覽。
- 按鍵：`0`～`9`、`00`、`.`、`+ − × ÷`、`=`、`C`（全部清除）、`⌫`（刪一格），以及最下方的「輸入」按鈕。
- 運算順序：先乘除、後加減（`1,200 + 350 × 2 = 1,900`）。
- 打開時顯示欄位目前的數字；這時直接按數字會取代它，按運算符號則接著算（例如 `+ 500`）。
- 按 `=`：算出結果，結果變成新的起點，可以繼續算。
- 按「輸入」：把結果填回欄位並關閉計算機。還沒按 `=` 也可以直接按「輸入」，會先算出結果。算式清空後按「輸入」，欄位會變成空白。
- 支出的金額經由計算機填入後，該列的主值變成「金額」。
- 錯誤（「輸入」按鈕停用）：除以 0 →「無法除以 0」；結果小於 0 →「金額不能是負數」。
- 結果保留到小數點後 2 位；欄位顯示時仍四捨五入到整數。
- 點計算機外面或往下關閉：不改變欄位。
- 電腦鍵盤也能操作：數字、`+ - * /`、`Enter`（=）、`Backspace`、`Esc`（關閉）。

### 5.6 拖曳排序

- 收入、支出每一列左側都有拖曳把手 ⠿。
- 按住把手上下拖曳，放開後順序就改好並自動儲存；只能在同一個區塊內移動。
- 拖曳中的那一列稍微浮起（陰影），其他列即時讓出位置。
- 拖到畫面上緣或下緣時，畫面會自動捲動。
- 只有按住把手才會拖曳，手指在其他地方滑動仍是正常捲動畫面。
- 鍵盤：把手取得焦點時，按 ↑ / ↓ 移動該列。

## 6. 摘要列（固定底部）

- 顯示：收入總計｜已分配｜剩餘
- **分配進度條**：0 → 100% 逐漸填滿；超過 100% 的部分變紅色。
- 吉祥物＋狀態文字（見第 7 節）。
- 超過 100% 時**只顯示警告，不禁止輸入**。

## 7. 視覺風格

### 7.1 方向

可愛、有一點遊戲感，但**不幼稚**；用語維持一般用語。

| 元素 | 設計 |
|---|---|
| 配色 | 奶油色背景、柔和粉嫩色系；收入用**薄荷綠**，支出用**蜜桃橘**，進度用**柚子橘**，超支用柔和的紅（色碼見 7.4） |
| 字型 | 數字用圓潤的 **Nunito**；中文用系統字（蘋方等）粗體 |
| 卡片／按鈕 | 大圓角＋與水豚同色的咖啡粗外框＋厚底，按下有「壓下去」的回饋 |
| 進度條 | 類似遊戲能量條，填滿時有動畫 |
| 小互動 | 新增列時輕微彈跳；剛好分配到 100% 時灑彩帶 |

### 7.2 吉祥物：水豚（Capybara）

- 定位：**佛系、穩重、有點呆萌**，不走大眼睛閃亮亮的超可愛路線。
- 造型：簡單線條、低彩度咖啡色、表情變化小但看得出來。
- 畫風：參考 `design/references/capybara-style.webp`，是原創繪製，不照抄參考圖。
  - 蠟筆質感的深咖啡粗外框
  - 圓胖的麻糬身形、小圓耳、露出兩隻小腳
  - 小黑點眼睛、粉紅腮紅、深色鼻子區塊加上「Y」字鼻嘴
- 素材：`design/mascot/capybara-{sleep,calm,done,sweat}.svg`，由 `design/mascot/build.py` 產生；要改顏色或造型就改這個檔，再重新產生。

| 狀態 | 吉祥物 | 文字 |
|---|---|---|
| 尚未填收入 | 閉眼睡覺 | 「先填入收入吧」 |
| 已分配 < 100% | 平靜坐著 | 「還有 NT$ X 可以分配」 |
| 已分配 = 100% | 頭上頂著一顆柚子，泡溫泉 | 「分配完成！」 |
| 已分配 > 100% | 冒一滴汗 | 「超出 X%（NT$ X）」 |

### 7.3 用語

一般用語：「收入」、「支出分配」、「＋ 新增收入」、「＋ 新增支出」。

### 7.4 設計 tokens 與視覺稿

- 所有顏色、字型、圓角、陰影都定義在 `design/tokens.css`，正式 App 直接引用，不另外寫死色碼。
- 視覺稿：`design/visual/v1.html`。

| Token | 色碼 | 用途 |
|---|---|---|
| `--bg` | #F6EBDD | 頁面背景 |
| `--surface` | #FFF9F1 | 卡片、面板 |
| `--outline` | #6B4A2F | 粗外框、厚底 |
| `--ink` | #5A4330 | 主要文字 |
| `--income` / `--income-soft` | #7CCBA8 / #E2F4EA | 收入 |
| `--expense` / `--expense-soft` | #F4AA80 / #FDE8DA | 支出 |
| `--yuzu` | #F5A040 | 進度條、目前方案 |
| `--over` / `--over-soft` | #E57F78 / #FBE0DD | 超支警告 |

### 7.5 元件細節

- **主值欄位**：蜜桃橘實線框。
- **計算欄位**（非主值）：虛線框、文字顏色較淡；點一下就能編輯，編輯後變成主值。
- **拖曳把手**：淡咖啡色 ⠿，點擊範圍至少 44px 高。
- **計算機**：底部面板；數字鍵白底、運算鍵蜜桃橘淡色、`=` 柚子橘、「輸入」是滿版的柚子橘按鈕；按鍵都有厚底，按下會往下壓。
- **目前方案標籤**：柚子橘淡色底、咖啡粗框＋厚底；其他方案是淡框。
- **摘要列**：圓角面板固定在底部，水豚從左上角探出頭；狀態文字放在對話框裡。超支時對話框變成淡紅色。
- **刪除方案按鈕**：淡紅底、紅字。

## 8. 預設內容

第一次開啟時建立一組名為「我的方案」的範例；新增方案也使用此範例。

- 收入：薪水（金額空白）
- 支出：🍙 吃飯 30%、🏠 房租 30%、🐷 儲蓄 20%、🎮 娛樂 10%（皆以 % 為主值）

## 9. 顯示與輸入規則

- 貨幣：NT$，金額加千分位（NT$ 47,800）。
- 計算出的金額四捨五入到整數；% 顯示到小數點後 1 位。
- % 欄位使用數字鍵盤（`inputmode="decimal"`）；點進欄位時自動全選，直接輸入就會取代舊數字。
- 金額欄位使用計算機（5.5），不叫出手機鍵盤。
- 輸入框字級至少 16px，避免 iPhone 點擊時自動放大畫面。
- 可點擊範圍至少 44 × 44 px。
- 不接受負數；非數字輸入忽略。

## 10. 資料儲存

- 存在瀏覽器 localStorage，每次修改自動儲存。
- 資料**不上傳**到任何伺服器。
- ⋯ 選單提供「清除全部資料」（需二次確認，清除後回到預設範例）。
- 已知限制：換手機、換瀏覽器或清除瀏覽器資料後，資料會消失（v2 可考慮匯出／匯入）。

### 10.1 資料結構

儲存的資料帶有 `schemaVersion`，日後資料結構改變時，用它把舊資料轉換成新格式，避免使用者資料遺失。

```ts
type AppData = {
  schemaVersion: 1;
  activePlanId: string;
  plans: Plan[];
};

type Plan = {
  id: string;
  name: string;
  createdAt: string; // ISO 8601
  updatedAt: string;
  incomes: Income[];
  expenses: Expense[];
};

type Income = {
  id: string;
  name: string;
  amount: number | null;
};

type Expense = {
  id: string;
  emoji: string;
  name: string;
  mode: "percent" | "amount"; // 主值
  value: number | null;      // mode=percent 時為 %，mode=amount 時為金額
};
```

另一欄（% 或金額）由主值和收入總計即時算出，不儲存。

## 11. 加到手機主畫面與離線使用

- 支援「加入主畫面」（iPhone Safari）和「加到主畫面／安裝應用程式」（Android Chrome）。
- 從主畫面打開時全螢幕顯示，沒有瀏覽器網址列（`display: standalone`）。
- 桌面圖示：奶油色底，加上頭頂柚子的水豚（`design/icons/`），由 `design/mascot/build.py` 和 `design/icons/render.sh` 產生。
- App 名稱：**小金芽**（英文 Goldbud）。
- 第一次打開後，App 的檔案會存在手機上，**沒有網路也能打開**（`sw.js`）。
- 發布新版後，下次打開 App 時會在背景下載新版，再下一次打開就是新版。
