## 1. 產品概述

- **目的**：輸入每月收入，用百分比或固定金額把收入分配到各個支出／儲蓄項目，讓財務規劃變得輕鬆好玩。
- **平台**：手機優先（mobile-first）網頁，用手機瀏覽器開啟即可；桌機也能正常顯示。
- **使用方式**：單一頁面，不需註冊登入，資料只存在使用者自己的瀏覽器。

## 2. 頁面結構（由上到下）

1. 標題列（App 名稱、⋯ 選單）
2. 方案標籤列
3. 收入區塊
4. 支出區塊
5. 摘要列（固定在畫面底部，含吉祥物）

## 3. 方案（多組）

- 頁面上方是可左右滑動的**方案標籤列**，例如：`我的方案`｜`加薪後`｜`＋`
- 每個方案各自擁有一份收入和支出清單。

| 功能 | 說明 |
|---|---|
| 新增 | 點「＋」建立新方案，內容為第 8 節的預設範例 |
| 複製 | 複製目前方案，方便比較不同情境 |
| 重新命名 | 點目前方案標籤的 ⋯ 選單 |
| 刪除 | 需二次確認；至少保留一組方案（只剩一組時刪除按鈕停用） |
| 切換 | 點標籤即切換；記住上次開啟的方案 |

## 4. 收入區塊

| 欄位 | 類型 | 規則 |
|---|---|---|
| 項目名稱 | 文字 | 例如：薪水、股息、兼職 |
| 金額 | 數字 | ≥ 0，可有小數；空白視為 0 |

- 「＋ 新增收入」：在清單最後新增一列空白項目。
- 每列有刪除按鈕。
- **收入總計** = 所有金額加總，即時更新。

## 5. 支出區塊

### 5.1 欄位

| 欄位 | 類型 | 規則 |
|---|---|---|
| 圖示 | emoji | 點擊可從清單選擇（🍙 🏠 🐷 🎮 🚌 💊 📚 🎁 …），預設 💸 |
| 項目名稱 | 文字 | 例如：吃飯、房租、儲蓄 |
| 百分比 % | 數字，可編輯 | 0～100，可有小數 |
| 金額 | 數字，可編輯 | ≥ 0 |

### 5.2 % ⇄ 金額 雙向計算

- 填 %：金額 = 收入總計 × %
- 填金額：% = 金額 ÷ 收入總計
- **最後編輯的欄位是該列的「主值」**，旁邊以 📌 標示。

收入總計改變時：

| 該列主值 | 結果 | 例子 |
|---|---|---|
| % | % 不變，金額重算 | 吃飯 30% |
| 金額 | 金額不變，% 重算 | 房租固定 13,000 |

- 收入總計為 0 時，以金額為主值的列，其 % 顯示「—」（不顯示錯誤）。

### 5.3 區塊小計

- **已分配**：% 合計與金額合計
- **未分配**：100% − 已分配 %，以及對應金額

### 5.4 操作

- 「＋ 新增支出」、每列刪除按鈕。

## 6. 摘要列（固定底部）

- 顯示：收入總計｜已分配｜剩餘
- **分配進度條**：0 → 100% 逐漸填滿；超過 100% 的部分變紅色。
- 吉祥物＋狀態文字（見第 7 節）。
- 超過 100% 時**只顯示警告，不禁止輸入**。

## 7. 視覺風格

### 7.1 方向

可愛、有一點遊戲感，但**不幼稚**；用語維持一般用語。

| 元素 | 設計 |
|---|---|
| 配色 | 奶油色背景、柔和粉嫩色系；收入用**薄荷綠**，支出用**蜜桃橘**，超支用柔和的紅 |
| 字型 | 圓體；數字用較粗的圓潤字型 |
| 卡片／按鈕 | 大圓角＋厚底邊陰影，按下有「壓下去」的回饋 |
| 進度條 | 類似遊戲能量條，填滿時有動畫 |
| 小互動 | 新增列時輕微彈跳；剛好分配到 100% 時灑彩帶 |

### 7.2 吉祥物：水豚（Capybara）

- 定位：**佛系、穩重、有點呆萌**，不走大眼睛閃亮亮的超可愛路線。
- 造型：簡單線條、低彩度咖啡色、表情變化小但看得出來。

| 狀態 | 吉祥物 | 文字 |
|---|---|---|
| 尚未填收入 | 閉眼睡覺 | 「先填入收入吧」 |
| 已分配 < 100% | 平靜坐著 | 「還有 NT$ X 可以分配」 |
| 已分配 = 100% | 頭上頂著一顆柚子，泡溫泉 | 「分配完成！」 |
| 已分配 > 100% | 冒一滴汗 | 「超出 X%（NT$ X）」 |

### 7.3 用語

一般用語：「收入」、「支出分配」、「＋ 新增收入」、「＋ 新增支出」。

## 8. 預設內容

第一次開啟時建立一組名為「我的方案」的範例；新增方案也使用此範例。

- 收入：薪水（金額空白）
- 支出：🍙 吃飯 30%、🏠 房租 30%、🐷 儲蓄 20%、🎮 娛樂 10%（皆以 % 為主值）

## 9. 顯示與輸入規則

- 貨幣：NT$，金額加千分位（NT$ 47,800）。
- 計算出的金額四捨五入到整數；% 顯示到小數點後 1 位。
- 數字欄位使用數字鍵盤（`inputmode="decimal"`）。
- 可點擊範圍至少 44 × 44 px。
- 不接受負數；非數字輸入忽略。

## 10. 資料儲存

- 存在瀏覽器 localStorage，每次修改自動儲存。
- 資料**不上傳**到任何伺服器。
- ⋯ 選單提供「清除全部資料」（需二次確認，清除後回到預設範例）。
- 已知限制：換手機、換瀏覽器或清除瀏覽器資料後，資料會消失（v2 可考慮匯出／匯入）。

### 10.1 資料結構

儲存的資料帶有 `schemaVersion`，日後資料結構改變時，用它把舊資料轉換成新格式，避免使用者資料遺失。

```ts
type AppData = {
  schemaVersion: 1;
  activePlanId: string;
  plans: Plan[];
};

type Plan = {
  id: string;
  name: string;
  createdAt: string; // ISO 8601
  updatedAt: string;
  incomes: Income[];
  expenses: Expense[];
};

type Income = {
  id: string;
  name: string;
  amount: number | null;
};

type Expense = {
  id: string;
  emoji: string;
  name: string;
  mode: "percent" | "amount"; // 主值
  value: number | null;      // mode=percent 時為 %，mode=amount 時為金額
};
```

另一欄（% 或金額）由主值和收入總計即時算出，不儲存。
