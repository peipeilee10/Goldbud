# 決策紀錄

記錄每個重要決定「選了什麼、為什麼」，之後回頭看才知道當初的考量。新的決定加在最下面，編號不重複使用；推翻舊決定時新增一筆，並在舊的那筆標註「已被 D-XXX 取代」。

| 編號 | 日期 | 決定 | 原因 |
|---|---|---|---|
| D-001 | 2026-10-23 | 做成手機優先的單頁網頁，不需登入 | 隨手打開就能用，門檻最低 |
| D-002 | 2026-10-23 | 資料存在瀏覽器 localStorage，不上傳伺服器 | 財務資料敏感；v1 不需要後端 |
| D-003 | 2026-10-23 | 支出可填 % 或金額，雙向計算 | 固定支出（如房租）填金額比較方便 |
| D-004 | 2026-10-23 | 最後編輯的欄位是主值；收入改變時主值不變 | 填 % 的跟著收入縮放，填金額的保持固定，符合直覺 |
| D-005 | 2026-10-23 | 超過 100% 只警告，不禁止輸入 | 調整過程中暫時超過很常見，禁止會很卡 |
| D-006 | 2026-10-23 | 預設內容用範例（吃飯 30%、房租 30%、儲蓄 20%、娛樂 10%） | 第一次打開就知道怎麼用 |
| D-007 | 2026-10-23 | 支援多組方案，可新增、複製、重新命名、刪除 | 可以比較不同情境，例如「現在」和「加薪後」 |
| D-008 | 2026-10-23 | 風格可愛、有遊戲感，但用語維持一般用語 | 讓財務規劃好玩，但資訊仍要一看就懂 |
| D-009 | 2026-10-23 | 吉祥物用水豚，走佛系、不過度可愛的路線 | 使用者指定；水豚的「淡定」形象和理財的穩健感相符 |
| D-010 | 2026-10-23 | 儲存資料帶 `schemaVersion` | 之後會持續加功能，資料結構改變時能安全轉換舊資料 |
| D-011 | 2026-10-23 | 水豚畫風參考使用者提供的蠟筆風圖片，用 SVG 原創繪製 | 使用者提供了喜歡的風格；用 SVG 畫，檔案小、手機上清楚，也方便之後加動畫或調整 |
| D-012 | 2026-10-23 | 數字用 Nunito，中文用系統字，不用中文圓體 | 免費的網路中文圓體多半是日文字型，繁中字會缺字、混字；系統字最穩定。之後可考慮自行放入「jf open 粉圓」 |
| D-013 | 2026-10-23 | 卡片和按鈕用咖啡粗外框＋厚底 | 和水豚的蠟筆外框統一，也做出遊戲按鈕的感覺 |
| D-014 | 2026-10-23 | 設計 tokens 集中在 `design/tokens.css` | 視覺稿和正式 App 共用同一份，之後改色只要改一處 |
| D-015 | 2026-10-23 | 用純 HTML／CSS／JavaScript（ES modules）開發，不用框架、不需要建置；測試用 Node 內建的 `node --test` | 沒有任何套件要安裝或更新，任何靜態網站空間都能直接放；計算和儲存邏輯獨立成模組，方便測試和之後擴充 |
| D-016 | 2026-10-23 | 數字欄位點進去時自動全選 | 手機上要刪掉舊數字很麻煩；全選後直接輸入就會取代 |
| D-017 | 2026-10-23 | 做成 PWA（manifest＋service worker），可以加到主畫面、離線使用 | 使用者想要桌面上像 App 的圖示；不需要上架 App Store，免費 |
| D-018 | 2026-10-23 | 桌面 PNG 圖示用 Chrome 無頭模式從 SVG 轉出 | iPhone 的主畫面圖示不支援 SVG；這台電腦沒有其他轉檔工具，用 Chrome 也能正確畫出蠟筆質感 |
| D-019 | 2026-10-23 | App 名稱改為「小金芽」（英文 Goldbud），GitHub repo 為 peipeilee10/Goldbud | 使用者指定 |
| D-020 | 2026-10-23 | 瀏覽器儲存 key 改為 `goldbud`，舊 key `budget-capybara` 的資料自動搬過來 | 名稱統一；趁還沒正式使用時改，並保留轉換避免資料遺失 |
| D-021 | 2026-10-23 | 水豚參考圖不放進 git（.gitignore） | 可能是別人的作品，專案公開時不應一起上傳 |
| D-022 | 2026-10-23 | 程式碼放在公開的 GitHub repo peipeilee10/Goldbud，用 GitHub Pages（main 分支根目錄）免費上線 | 備份＋免費網址；程式碼裡沒有使用者的財務資料，資料只存在各自手機的瀏覽器 |
| D-023 | 2026-10-23 | 上傳前整理 git 歷史：作者改用 GitHub 隱私信箱、移除參考圖 | 公開後歷史紀錄任何人都看得到，避免外流電腦名稱和別人的作品 |
| D-024 | 2026-10-24 | 收入、支出可以拖曳排序，只有按住左側把手 ⠿ 才拖曳 | 使用者回饋；用把手可以避免和捲動畫面、點輸入框衝突 |
| D-025 | 2026-10-24 | 金額欄位改用自製計算機輸入，計算先乘除後加減 | 使用者回饋：金額常常是好幾筆加總；先乘除後加減和手機內建計算機一致 |
| D-026 | 2026-10-24 | 移除主值的 📌 圖示，只用實線／虛線框區分 | 使用者回饋：圖示沒有意義、佔空間 |
