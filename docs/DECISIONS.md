# 決策紀錄

記錄每個重要決定「選了什麼、為什麼」，之後回頭看才知道當初的考量。新的決定加在最下面，編號不重複使用；推翻舊決定時新增一筆，並在舊的那筆標註「已被 D-XXX 取代」。

| 編號 | 日期 | 決定 | 原因 |
|---|---|---|---|
| D-001 | 2026-10-23 | 做成手機優先的單頁網頁，不需登入 | 隨手打開就能用，門檻最低 |
| D-002 | 2026-10-23 | 資料存在瀏覽器 localStorage，不上傳伺服器 | 財務資料敏感；v1 不需要後端 |
| D-003 | 2026-10-23 | 支出可填 % 或金額，雙向計算 | 固定支出（如房租）填金額比較方便 |
| D-004 | 2026-10-23 | 最後編輯的欄位是主值；收入改變時主值不變 | 填 % 的跟著收入縮放，填金額的保持固定，符合直覺 |
| D-005 | 2026-10-23 | 超過 100% 只警告，不禁止輸入 | 調整過程中暫時超過很常見，禁止會很卡 |
| D-006 | 2026-10-23 | 預設內容用範例（吃飯 30%、房租 30%、儲蓄 20%、娛樂 10%） | 第一次打開就知道怎麼用 |
| D-007 | 2026-10-23 | 支援多組方案，可新增、複製、重新命名、刪除 | 可以比較不同情境，例如「現在」和「加薪後」 |
| D-008 | 2026-10-23 | 風格可愛、有遊戲感，但用語維持一般用語 | 讓財務規劃好玩，但資訊仍要一看就懂 |
| D-009 | 2026-10-23 | 吉祥物用水豚，走佛系、不過度可愛的路線 | 使用者指定；水豚的「淡定」形象和理財的穩健感相符 |
| D-010 | 2026-10-23 | 儲存資料帶 `schemaVersion` | 之後會持續加功能，資料結構改變時能安全轉換舊資料 |
| D-011 | 2026-10-23 | 水豚畫風參考使用者提供的蠟筆風圖片，用 SVG 原創繪製 | 使用者提供了喜歡的風格；用 SVG 畫，檔案小、手機上清楚，也方便之後加動畫或調整 |
| D-012 | 2026-10-23 | 數字用 Nunito，中文用系統字，不用中文圓體 | 免費的網路中文圓體多半是日文字型，繁中字會缺字、混字；系統字最穩定。之後可考慮自行放入「jf open 粉圓」 |
| D-013 | 2026-10-23 | 卡片和按鈕用咖啡粗外框＋厚底 | 和水豚的蠟筆外框統一，也做出遊戲按鈕的感覺 |
| D-014 | 2026-10-23 | 設計 tokens 集中在 `design/tokens.css` | 視覺稿和正式 App 共用同一份，之後改色只要改一處 |
